# 中国官方政府人员资料源调查

调查时间：2026-10-16。以下来源适合纳入 HumanMap 的“人物—任职主张—来源证据”模型。应以页面实际发布日期和抓取时间为准，不把当前页面内容直接视为永久事实。

## 优先级 A：适合第一批接入

### 1. 国务院组织机构

入口：<https://www.gov.cn/gwyzzjg/index.htm>

可获得：国务院组成部门、直属特设机构、直属机构、办事机构、直属事业单位、部委管理国家局、议事协调机构等机构目录。页面还提供机构详情和部分机构官网链接。

适合抽取：

- 组织实体：机构名称、机构类型、官网、上级机构；
- 人物实体：部长、主任、局长、秘书长、负责人；
- 任职主张：人物—所属组织—职务；
- 来源：国务院组织机构页和机构官网。

注意：国务院页面是组织结构目录，不一定为每个机构提供完整领导名单。应将机构目录和机构官网领导栏目合并，而不是只抓一个入口。

### 2. 中国政府网国务院栏目

入口：<https://www.gov.cn/guowuyuan/index.htm>

可获得：国务院领导活动、国务院常务会议、政府工作、人事任免、政策文件和机构相关新闻。

适合抽取：

- 国务院领导人物资料；
- 人事任免事件；
- 任职时间线；
- 会议参与人物；
- 人物与国务院组成部门的组织关系。

建议以“人事任免”类页面作为任职主张来源，以活动报道作为补充来源，不要从普通新闻标题直接推断任职起止日期。

### 3. 中国人民政治协商会议全国委员会

入口：<http://www.cppcc.gov.cn/>

相关栏目：

- 领导：<http://www.cppcc.gov.cn/zxld/>
- 机构设置：<http://www.cppcc.gov.cn/jgzc/>
- 委员履职：<http://www.cppcc.gov.cn/wylz/>

可获得：全国政协主席、副主席、秘书长、专门委员会负责人、委员名单、委员履职信息和专门委员会结构。

适合抽取：

- 政协领导人物；
- 全国政协委员；
- 专门委员会及负责人；
- 委员所属界别；
- 履职文章和任期证据。

建议将“委员名单”和“委员履职文章”分为两种来源类型，名单用于身份/任期，文章用于活动事实。

### 4. 全国人民代表大会

入口：<https://www.npc.gov.cn/>

建议重点寻找和接入：

- 全国人大常委会领导；
- 全国人大常委会委员；
- 各专门委员会；
- 代表名单和代表履职信息；
- 任免事项、公报和会议文件。

由于全国人大站点存在部分 TLS、反爬和页面改版问题，应优先使用官方网站可公开访问的栏目页，记录 HTTP 状态、最终 URL、页面编码和抓取时间。不要用搜索引擎摘要替代原始页面。

## 优先级 C：党政、监察、司法和军队相关公开信息

可研究但需要更严格边界：

- 中共中央纪律检查委员会、国家监察委员会：<http://www.ccdi.gov.cn/>
- 国家监察委员会相关公开通报；
- 最高人民法院：<https://www.court.gov.cn/>
- 最高人民检察院：<https://www.spp.gov.cn/>
- 中国共产党新闻网领导资料专题：<http://cpc.people.com.cn/>
- 中国政府网人事任免栏目；
- 各省级人民政府、人大、政协官方网站；
- 各省组织部门和政府任免公告。

这些来源适合抽取“公告、任免、会议、通报”事件，但不应据此自动生成未经证实的政治关系、派系关系或个人评价。

## 推荐的数据抽取范围

第一阶段建议只抽取以下字段：

```text
人物：稳定 ID、姓名、别名、性别（仅当官方明确提供）、简历原文摘要
组织：稳定 ID、名称、组织类型、官网、上级组织
任职：人物、组织、职务、开始日期、结束日期、状态
来源：标题、URL、发布日期、抓取时间、来源机构、页面摘要
事件：任免、换届、会议、辞职、免职、机构调整
```

不建议第一阶段自动抽取：

- 家庭关系；
- 未经来源明确表达的政治关系；
- 从照片、座次或新闻共同出现推断的关系；
- 个人财产、健康、私人联系方式；
- 由新闻标题推断的完整任职期限。

## 抓取和审核规则

1. 每个站点遵守 robots、服务条款和访问频率限制；
2. 默认每域名请求间隔 0.5～2 秒；
3. 保存最终 URL、状态码、编码、抓取时间和解析器版本；
4. 对 301/302 重定向保留原 URL 和最终 URL；
5. HTTP 页面不自动升级为 HTTPS 后丢弃原始地址；
6. 抓取失败不写入人物事实，只写入批次错误报告；
7. 同一人物同一来源文章只保留一份；
8. 同名人物必须依靠来源中的职务、机构、简历、任职时间人工确认；
9. 自动抽取的任职记录状态为 `unreviewed`；
10. 静态发布前必须通过 ID、来源、引用和批次完整性检查。

## 推荐实施次序

1. 国务院组织机构目录；
2. 国务院领导和人事任免；
3. 全国政协领导、委员和专门委员会；
4. 全国人大常委会、专门委员会和代表公开信息；
5. 重点部委领导栏目；
6. 省级政府领导和人事任免；
7. 最高法、最高检、纪委监委等公告型来源。

第一批不建议直接抓取所有部委新闻全文。应先抓机构和人物目录，再用任免公告补充时间线，最后将新闻报道作为证据和事件资料。
